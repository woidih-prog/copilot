# Photos des plats

Mets ici les photos des plats, une par plat, nommée avec l'identifiant du plat : `p08.jpg` pour le poulet rôti.

- Format carré, environ 800 × 800 px, moins de 200 Ko (JPG ou WebP).
- Le plat vu de dessus ou de trois quarts, sur un fond simple : c'est ce qui rend le mieux dans l'appli.
- Utilise tes propres photos, ou des photos dont tu as le droit (libres de droits, avec la licence respectée).

Ensuite, ajoute une ligne dans `PHOTOS` à la fin de `recettes.js`, par exemple :

```js
const PHOTOS = {
  p08:"photos/p08.jpg",
};
```
